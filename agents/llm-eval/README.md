# LLM Eval

Сравнить модели и промпты на фиксированном контрольном наборе с учётом качества, стоимости и задержки.

## Запуск

Команды выполняются из корня общего репозитория. Нужен Node.js 22+.

```sh
node agents/llm-eval/run.mjs --input agents/llm-eval/example.json --output output/llm-eval.json
```

Пример [example.json](example.json) содержит синтетические данные. Результат сохраняется в JSON. Exit code 0 означает passed, 1 означает failed или review, 2 означает ошибку входных данных или запуска. Существующий отчёт сохраняется при ошибке валидации входа.

## Входные данные

`cases` содержит ID и эталонные строки. `runs` содержит ID запуска, caseId, model, output, inputTokens, outputTokens и latencyMs. `pricesUsdPerMillion` задаёт цены, а `thresholds` — минимальный exact match и максимальные стоимость набора и p95.

## Что проверяется

Считает точное совпадение, полноту покрытия, ошибки запросов, p95 по ближайшему рангу и стоимость. Рекомендует самый дешёвый вариант, прошедший все пороги. Повторное наблюдение пары model/caseId отклоняется, чтобы не давать модели преимущество за счёт повторов.

## Работа с coding-агентом

Откройте корень репозитория и используйте [skill llm-eval](../../.agents/skills/llm-eval/SKILL.md).

> Используй llm-eval для моего проекта. Сверь исходные данные, выполни проверку и объясни результат с конкретными доказательствами.

Зафиксируй версии промптов, контрольный набор и критерии до сравнения моделей. Собери ответы, ошибки, реальный usage и задержки на одинаковых кейсах. Используй одинаковый протокол замера и отделяй разминку от измеряемых запросов. Для открытых ответов согласуй рубрику и выборку ручной проверки. После CLI разбери провальные кейсы и предложи модель только при полном покрытии и соблюдении порогов.

## Границы проверки

Exact match подходит для структурированных и коротких эталонных ответов. Для открытых ответов skill отдельно оценивает смысловую корректность на размеченных данных. Числа из example.json синтетические. Цены задаёт пользователь, обращения к платным API выполняются в отдельно разрешённом запуске.
