# RAG QA

Проверить качество извлечения документов, наличие цитируемых фрагментов, актуальность источников и корректность отказа при отсутствии ответа.

## Запуск

Команды выполняются из корня общего репозитория. Нужен Node.js 22+.

```sh
node agents/rag-qa/run.mjs --input agents/rag-qa/example.json --output output/rag-qa.json
```

Пример [example.json](example.json) содержит синтетические данные. Результат сохраняется в JSON. Exit code 0 означает passed, 1 означает failed или review, 2 означает ошибку входных данных или запуска. Существующий отчёт сохраняется при ошибке валидации входа.

## Входные данные

`documents` задаёт id, text и updatedAt. `cases` содержит expectedDocumentIds, retrievedDocumentIds, answer, citations и abstained. `now` фиксирует время оценки, `thresholds` задаёт минимальный recall и максимальный возраст документа.

## Что проверяется

Считает recall по эталонным документам и reciprocal rank первого релевантного результата. Находит несуществующие и устаревшие документы, повторы в выдаче, неподтверждённые цитаты и ответы на вопросы без эталонного источника.

## Работа с coding-агентом

Откройте корень репозитория и используйте [skill rag-qa](../../.agents/skills/rag-qa/SKILL.md).

> Используй rag-qa для моего проекта. Сверь исходные данные, выполни проверку и объясни результат с конкретными доказательствами.

Составь вопросы с эталонными источниками и отдельные вопросы без ответа в базе. Зафиксируй снимок документов и время оценки. Получи фактическую выдачу RAG, ответ и цитаты. После CLI вручную проверь смысловую поддержку каждого существенного утверждения и раздели ошибки retrieval, генерации и устаревших данных. Перепроверь исправление на том же наборе.

## Границы проверки

Наличие буквальной цитаты проверяется автоматически. Семантическую связь утверждений с источником оценивает skill. Дата now передаётся явно для воспроизводимости. Возраст документа сам по себе является сигналом проверки и зависит от требований конкретной базы знаний.
