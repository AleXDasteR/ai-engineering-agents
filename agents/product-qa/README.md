# Product QA Agent

Агент проверяет продукт по пользовательским сценариям, находит воспроизводимые ошибки и формирует отчёт с доказательствами. Skill ведёт анализ требований и UI-проверки, CLI выполняет повторяемые сценарии из плана.

## Запуск с coding-агентом

Skill находится в [.agents/skills/product-qa](../../.agents/skills/product-qa/SKILL.md) и доступен при работе из этого репозитория.

Пример запроса

> Используй product-qa для проекта в C:/projects/hearth-ledger. Проверь историю матчей, расчёты соло и дуэтов и рекомендации по доске. Сохрани отчёт и шаги воспроизведения найденных ошибок.

## Автоматизированный запуск

Все команды выполняются из корня репозитория агентов. Нужен Node.js 22+. Для адаптера Hearth Ledger нужны Windows, .NET Framework и установленный HDT.

```powershell
node agents/product-qa/run.mjs --project "C:/projects/hearth-ledger" --plan adapters/hearth-ledger/product.plan.json --hdt "$env:LOCALAPPDATA/HearthstoneDeckTracker/current" --output output/hearth-ledger-product
```

Результат появится в `output/hearth-ledger-product/product-qa.json`. В нём статус каждой проверки, точная команда, код выхода, время выполнения, stdout/stderr и список ручных сценариев. Успех возвращает код 0, падение или недоступный инструмент — код 1.

## Подключение другого продукта

Создайте JSON-план с массивом `checks`. Каждая проверка задаёт `id`, исполняемый файл `command`, массив аргументов `args`, `timeoutMs` и регулярные выражения `paths`. Пример формата находится в [плане Hearth Ledger](../../adapters/hearth-ledger/product.plan.json).

Поддерживаются подстановки `{project}`, `{repo}`, `{output}`, `{node}`, `{hdt}`. Последняя требует `--hdt`. Команда запускается отдельным процессом с сохранением границ аргументов. Для npm на Windows используйте JS-вход CLI или явный разрешённый executable.

План является исполняемой конфигурацией и должен быть проверен владельцем проекта. Логи могут содержать данные приложения. Храните исходные отчёты локально, перед публикацией подготовьте обезличенное описание.

## Что проверено

На Hearth Ledger выполнены 12 сценариев по исходным Stats.cs и Recommendations.cs с настоящей HearthDb.dll. Найдена ошибка исправления режима уже записанного матча. Подробности находятся в [отчёте](../../reports/hearth-ledger-2026-11-21.md).

CLI запускает сценарии из плана. Визуальная приёмка оверлея и Tier7 требует отдельного запуска приложения через UI-инструменты. Эти пункты явно перечислены в `manualChecks`.
