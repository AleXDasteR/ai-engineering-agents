# Работа с репозиторием

Проект содержит девять агентов. Каталог и назначение каждого находятся в README. Выполняйте изменения через обычные CLI входы и сохраняйте формат входных JSON для существующих примеров.

Перед завершением запустите `node --test` и запуск node scripts/demo-agents.mjs, а также команду демо поиска из README агента. При изменении test runner проверьте реальный CLI запуск на плане. Отмечайте отдельно ошибки продукта, ограничения окружения и непроверенные UI-сценарии. Для публикации используйте демонстрационные данные и обезличенные отчёты.

Запрос на разработку в этом репозитории разрешает локальную разработку и проверки. Действия на hh.ru, отправка анкет и сообщения работодателям зависят от явного запроса пользователя в текущей задаче.
