# Формат снимков вакансий

CLI принимает массив объектов из JSON. Поля извлекает browser-агент после чтения страницы. Для каждого условия сохраняйте текстовое подтверждение в приватном отчёте. JSON нужен для воспроизводимой проверки формальных ограничений.

| Поле | Значение |
| --- | --- |
| `id` | Стабильный ID вакансии, строка |
| `companyId` | ID работодателя, если доступен |
| `company` | Название работодателя |
| `title` | Название вакансии |
| `url` | HTTPS-ссылка на прочитанную страницу |
| `observedAt` | Дата и время чтения, рекомендуемое поле |
| `description` | Полный видимый текст описания |
| `descriptionRead` | Булево подтверждение полного прочтения |
| `remote` | `true`, `false` или `null`, если неизвестно |
| `city` | Город для работы в офисе |
| `requiredYears` | Минимальное требование по стажу в годах, число или `null` |
| `contract` | `employment`, `self-employed`, `contractor`, `entrepreneur-only` или `null` |
| `primaryStack` | Основной стек, например `python`, `python-typescript`, `llm-integration`, `java` или `null` |
| `salary` | Объект `{ "from": 100000, "to": 150000, "currency": "RUB" }` или `null` |

Для вилки с одной границей укажите только `from` или `to`. Сохраняйте период выплаты и gross/net в дополнительных полях `salaryPeriod` и `salaryBasis`. Модуль ожидает месячную сумму, `salaryPeriod` равен `month` по умолчанию. Другие периоды переходят в `review`. Почасовые, проектные выплаты и неоднозначные суммы требуют ручного пересчёта с явными допущениями перед запуском. Неизвестную валюту добавьте в конфиг с проверенным курсом.

Фраза «Python будет плюсом» при основном стеке Java даёт `primaryStack: "java"`. Список навыков не заменяет чтения обязанностей. `remote: true` не доказывает доступность роли из любой страны, ограничения нужно проверить отдельно.

Журнал представляет собой массив объектов с `company`, необязательными `companyId` и `vacancyId`. В него включаются отправленные отклики и случаи, по которым пользователь уже ведёт общение. Исторически отсеянные по изменившемуся критерию вакансии пересмотрите отдельно перед включением в журнал исключений.

Пример приватного профиля

```json
{
  "name": "Имя кандидата",
  "readyToStart": "после подтверждения кандидатом",
  "facts": [
    {
      "project": "Пример проекта",
      "contribution": "Лично реализованная часть",
      "result": "Проверенный результат и способ измерения",
      "source": "Резюме или подтверждение кандидата"
    }
  ],
  "gaps": ["Технологии без подтверждённого практического опыта"]
}
```
